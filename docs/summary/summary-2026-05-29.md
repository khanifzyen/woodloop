## 2. Perbaikan Form Submit (New Inventory)
Kami memperbaiki cara pengiriman form di halaman `inventory/new`.

*   **Masalah:** Kode sebelumnya membuat temp record dengan `supplier: ""` dan tanpa `shape`, lalu menghapusnya — menyebabkan error "shape: cannot be blank, supplier: cannot be blank".
*   **Solusi:** Mengganti seluruh `handleSubmit` dengan FormData langsung, mengirim semua field (supplier, shape, photos sebagai file) dalam satu request ke PocketBase.
*   **Perubahan Kode:**
    *   `src/app/(dashboard)/supplier/inventory/new/page.tsx` — hapus temp record hack, kirim FormData.
    *   `src/lib/hooks/use-supplier.ts` — `useCreateRawTimberListing` sekarang terima `FormData`, bukan `CreateTimberData`.

## 3. Client-Side Image Resize

*   **File Baru:** `src/lib/resize-image.ts` — fungsi resize via Canvas, maks 1024px di sisi terpanjang, kualitas JPEG 0.85.

*   **Dampak:** Ukuran file foto berkurang signifikan, upload lebih cepat.

## 4. Perbaikan URL Foto (Inventory List & Card)
Kami memperbaiki foto yang tidak muncul di daftar inventaris.

*   **Masalah:** PocketBase hanya mengembalikan nama file (contoh: `05_20000prompt_rjl55lsr27.png`), bukan full URL. Tag `<img src={filename}>` menghasilkan broken image.
*   **Solusi:** Menambahkan `getFileUrl()` di `src/lib/pocketbase/client.ts` yang menggunakan `pb.files.getURL()` bawaan SDK PocketBase untuk membangun full URL dari `collectionId`, `recordId`, dan filename.
*   **Penerapan:**
    *   `src/app/(dashboard)/supplier/inventory/page.tsx` — thumbnail tabel pakai `getFileUrl`.
    *   `src/components/features/timber-card.tsx` — gambar kartu pakai `getFileUrl`.
