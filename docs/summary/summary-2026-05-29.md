## 4. Perbaikan URL Foto (Inventory List & Card)
Kami memperbaiki foto yang tidak muncul di daftar inventaris.

*   **Masalah:** PocketBase hanya mengembalikan nama file (contoh: `05_20000prompt_rjl55lsr27.png`), bukan full URL. Tag `<img src={filename}>` menghasilkan broken image.
*   **Solusi:** Menambahkan `getFileUrl()` di `src/lib/pocketbase/client.ts` yang menggunakan `pb.files.getURL()` bawaan SDK PocketBase untuk membangun full URL dari `collectionId`, `recordId`, dan filename.
*   **Penerapan:**
    *   `src/app/(dashboard)/supplier/inventory/page.tsx` — thumbnail tabel pakai `getFileUrl`.
    *   `src/components/features/timber-card.tsx` — gambar kartu pakai `getFileUrl`.

## 10. Perbaikan Dokumen Legalitas (FormData & Preview)
Kami memperbaiki dokumen legalitas yang tidak masuk ke PocketBase dan tidak tampil di halaman edit.

*   **Masalah New:** `legalityDoc` state ada tapi tidak di-append ke FormData — dokumen tidak pernah terkirim.
*   **Masalah Edit:** `handleSubmit` masih kirim JSON object, bukan FormData — foto baru dan dokumen tidak bisa diupload. Dokumen existing juga tidak tampil karena `getFileUrl()` tidak dipanggil untuk `legality_doc`.
*   **Solusi:** 
    *   `inventory/new` — menambahkan `formData.append("legality_doc", file)`.
    *   `inventory/[id]/edit` — `handleSubmit` diubah ke FormData, hook `useUpdateRawTimberListing` diubah dari `{ id, data }` ke `{ id, formData }`.
    *   `existingDoc` state dibuat dan diisi via `getFileUrl()` — dokumen existing tampil di FileDropzone.
*   **Perubahan Kode:**
    *   `src/lib/hooks/use-supplier.ts` — hapus `CreateTimberData`, `useUpdateRawTimberListing` terima FormData.
    *   `src/app/(dashboard)/supplier/inventory/[id]/edit/page.tsx` — `handleSubmit` pakai FormData, tambah `existingDoc` state, render `initialFiles={existingDoc}`.
    *   `src/app/(dashboard)/supplier/inventory/new/page.tsx` — append `legality_doc` ke FormData.

## 13. Perbaikan `getFileUrl` — dari SDK ke URL Manual
Kami mengubah implementasi `getFileUrl` karena `pb.files.getURL()` terkadang gagal di runtime.

*   **Sebelumnya:** `pb.files.getURL(record, filename)` — bergantung pada SDK internal state dan `collectionId` dari record.
*   **Sesudahnya:** URL konstruksi manual — `${PB_URL}/api/files/${collectionName}/${recordId}/${filename}` — lebih stabil karena pakai nama koleksi yang sudah pasti.
*   **Update Semua Pemanggil:** 12 file di-update signature dari `(record, filename)` ke `(collectionName, recordId, filename)`.
