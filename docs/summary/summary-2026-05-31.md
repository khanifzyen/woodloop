## 1. Generator — Perbaikan Bug (4 Issues)

### 1a. Report-Waste Temp Record Hack
*   **Masalah:** Kode membuat temp record dengan `generator: ""` untuk upload foto, lalu dihapus — menyebabkan error `generator: cannot be blank` dan foto gagal upload.
*   **Solusi:** Ganti dengan FormData langsung, kirim semua field + foto dalam satu request.
*   **File:** `src/app/(dashboard)/generator/report-waste/page.tsx`, `src/lib/hooks/use-generator.ts`

### 1b. Foto Produk Tidak Muncul
*   **Masalah:** `products/page.tsx` pakai `<img src={product.photos[0]}>` langsung tanpa `getFileUrl`.
*   **Solusi:** Ganti ke `getFileUrl("generator_products", ...)`.
*   **File:** `src/app/(dashboard)/generator/products/page.tsx`

### 1c. Upload Foto Produk Tidak Terkirim
*   **Masalah:** `products/new` collect file via FileDropzone tapi kirim `photos: []` ke mutation — foto tidak pernah diupload.
*   **Solusi:** `handleSubmit` bikin FormData dengan field + file foto. `useCreateGeneratorProduct` terima FormData.
*   **File:** `src/app/(dashboard)/generator/products/new/page.tsx`, `src/lib/hooks/use-generator.ts`

### 1d. Search Marketplace Kayu
*   **Masalah:** Filter search `wood_type ~ "${search}"` — `wood_type` adalah relation ID, bukan teks — tidak cocok.
*   **Solusi:** Hapus `wood_type ~` dari filter, hanya pakai `description ~`.
*   **File:** `src/lib/hooks/use-generator.ts`
