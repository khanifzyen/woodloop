## 4. Perubahan Dimensi Dinamis Berdasarkan Shape
Kami mengubah input dimensi agar menyesuaikan secara otomatis saat shape diganti.

*   **Log (Gelondongan):** Menampilkan input **Diameter (cm)** + **Panjang (cm)** (2 kolom).
*   **Sawn (Papan Gergajian):** Menampilkan input **Panjang (cm)** + **Lebar (cm)** + **Tinggi (cm)** (3 kolom).
*   **Data Dikirim:** `diameter`, `length`, `width`, `height` dikirim sesuai shape; field yang tidak terpakai bernilai `undefined`.
*   **Penerapan:** Berlaku di halaman `inventory/new` dan `inventory/[id]/edit`.

## 6. Perhitungan Volume Otomatis
Kami menambahkan perhitungan volume otomatis saat fokus ke field volume.

*   **Log:** `V = π × (d/200)² × (l/100)` — volume silinder dalam m³.
*   **Sawn:** `V = (p/100) × (l/100) × (t/100)` — volume balok dalam m³.
*   **Perilaku:** Hanya mengisi jika volume masih kosong; user tetap bisa mengedit manual setelahnya.

## 7. Thousand Separator pada Input Harga
Kami mengubah input harga agar menampilkan pemisah ribuan.

*   Input menggunakan `type="text"` + `inputMode="numeric"`.
*   Format: `toLocaleString("id-ID")` — contoh: `1.500.000`.
*   Nilai yang dikirim ke API tetap angka murni (tanpa separator).
