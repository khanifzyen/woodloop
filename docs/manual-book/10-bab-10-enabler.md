# Bab 10: Panduan Enabler (Pemerintah & Asosiasi)

---

**Enabler** adalah pemantau ekosistem — pihak yang memantau dampak lingkungan dan ekonomi dari kegiatan ekonomi sirkular di WoodLoop.

**Contoh pengguna Enabler:** Dinas Lingkungan Hidup Jepara, ASMINDO, Dinas Perindustrian.

---

## 10.1 Dashboard Enabler

Dashboard Enabler menampilkan **data dan grafik dampak** dari seluruh aktivitas di platform.

![Dashboard Enabler](screenshots/26-enabler-dashboard.png)
*Gambar 10.1 — Dashboard Enabler*

| Metrik | Contoh |
|--------|--------|
| **Limbah Terpakai** | Total limbah yang berhasil dialihkan dari TPA (contoh: 15.000 kg) |
| **CO₂ Tersimpan** | Estimasi emisi karbon yang terhindarkan (contoh: 2.500 kg CO₂) |
| **Nilai Ekonomi** | Total nilai transaksi di ekosistem (contoh: Rp 125.000.000) |
| **Pengguna Aktif** | Jumlah pengguna yang aktif bertransaksi (contoh: 250) |

**Grafik yang tersedia:**

| Grafik | Kegunaan |
|--------|----------|
| **Tren Limbah per Bulan** | Melihat peningkatan pengelolaan limbah |
| **Transaksi per Role** | Membandingkan kontribusi tiap role |
| **Distribusi Geografis** | Melihat daerah dengan aktivitas terbanyak |
| **Jenis Limbah** | Komposisi limbah yang dikelola |

**Filter:** Periode waktu (hari/minggu/bulan/tahun/kustom), wilayah (kecamatan), per role.

## 10.2 Manajemen Pengguna

Halaman **Manajemen User** untuk melihat dan mengelola seluruh pengguna WoodLoop.

![Manajemen User](screenshots/27-enabler-users.png)
*Gambar 10.2 — Halaman manajemen pengguna*

| Kolom | Keterangan |
|-------|------------|
| **Nama** | Nama lengkap pengguna |
| **Email** | Email terdaftar |
| **Peran** | Supplier, Generator, Aggregator, Converter, Buyer, Enabler |
| **Bergabung** | Tanggal registrasi |
| **Verifikasi** | Terverifikasi / Belum |
| **Aksi** | Detail, verifikasi, nonaktifkan |

| Fitur | Fungsi |
|-------|--------|
| **Pencarian** | Cari berdasarkan nama, email, atau peran |
| **Filter Peran** | Tampilkan per role tertentu |
| **Verifikasi Akun** | Setujui/tolak permintaan verifikasi |
| **Nonaktifkan** | Nonaktifkan akun yang melanggar aturan |
| **Ekspor Data** | Download data pengguna (CSV/Excel) |

### Proses Verifikasi

1. Enabler mendapat notifikasi **"Permintaan Verifikasi Baru"**
2. Buka Manajemen User → filter **"Menunggu Verifikasi"**
3. Lihat dokumen yang diupload pengguna
4. Pilih **Setujui** (badge biru aktif) atau **Tolak** (sertakan alasan)

### Laporan & Ekspor Data

| Jenis Laporan | Format | Kegunaan |
|---------------|--------|----------|
| Data Transaksi | CSV, Excel | Laporan ekonomi sirkular |
| Data Pengguna | CSV | Database peserta program |
| Data Limbah | CSV | Laporan pengelolaan limbah |
| Data Dampak | CSV, PDF | Laporan keberlanjutan |
