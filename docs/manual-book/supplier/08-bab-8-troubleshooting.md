# Bab 8: Troubleshooting

---

## 8.1 Tidak Bisa Login

**Masalah:** Gagal login meskipun email dan password sudah dimasukkan.

**Solusi:**
1. Pastikan email yang dimasukkan sudah benar (tidak ada spasi di depan/belakang)
2. Pastikan password benar — password bersifat **case-sensitive**
3. Periksa koneksi internet
4. Jika lupa password, klik **"Lupa Kata Sandi?"** di halaman login
5. Masukkan email terdaftar, ikuti instruksi reset yang dikirim ke email

> **Catatan:** Untuk keamanan, sistem tidak menampilkan detail error login secara spesifik. Jika gagal, periksa kembali email dan password Anda.

---

## 8.2 Foto Gagal Upload

**Masalah:** Foto kayu gagal diupload saat mendaftarkan atau mengedit kayu.

**Solusi:**
1. Periksa format foto — gunakan JPG, PNG, atau WebP
2. Pastikan ukuran foto tidak terlalu besar (maks 5 MB per foto)
3. Pastikan jumlah foto tidak melebihi 5 file
4. Coba gunakan browser lain (Chrome atau Firefox)
5. Refresh halaman dan coba upload ulang

---

## 8.3 Data Tidak Muncul Setelah Hapus

**Masalah:** Setelah menghapus kayu, data masih terlihat beberapa saat.

**Solusi:**
1. **Tunggu beberapa detik** — sistem akan memperbarui tampilan secara otomatis
2. **Refresh halaman** — tekan F5 atau klik tombol refresh browser
3. Jika masih muncul setelah refresh, coba **clear cache browser** atau buka di tab baru

> **Catatan:** Data akan langsung terhapus dari database. Tampilan akan terupdate dalam hitungan detik.

---

## 8.4 Lokasi GPS Tidak Akurat

**Masalah:** Lokasi workshop di peta tidak sesuai dengan lokasi sebenarnya.

**Solusi:**
1. **Drag marker** — Seret marker 📍 ke posisi yang benar secara manual
2. **Klik peta** — Klik langsung di lokasi yang diinginkan
3. **Pastikan izin lokasi aktif** — Browser harus diizinkan mengakses lokasi
4. **Aktifkan GPS** — Pastikan GPS perangkat Anda aktif (terutama di laptop/HP)
5. Jika menggunakan WiFi, akurasi GPS mungkin kurang presisi
