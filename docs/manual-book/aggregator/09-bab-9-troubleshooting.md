# Bab 9: Troubleshooting

---

## 9.1 Tidak Bisa Login

| Masalah | Solusi |
|---------|--------|
| Lupa password | Klik **"Lupa Kata Sandi?"** di halaman login, ikuti instruksi reset |
| Email tidak terdaftar | Pastikan mendaftar dengan peran Aggregator terlebih dahulu |
| Salah peran | Pastikan memilih **Aggregator** saat login, bukan peran lain |
| Browser error | Coba gunakan browser berbeda atau mode incognito |

---

## 9.2 Treasure Map Tidak Memuat

| Masalah | Solusi |
|---------|--------|
| Peta kosong / tidak ada marker | Mungkin belum ada limbah tersedia di sekitar, coba perluas filter jarak |
| Peta tidak muncul | Pastikan koneksi internet stabil (Leaflet memuat tile map dari server eksternal) |
| Izin lokasi ditolak | Treasure Map tetap bisa digunakan tanpa GPS, hanya fitur routing yang terbatas |

---

## 9.3 Bid Gagal Dikirim

| Masalah | Solusi |
|---------|--------|
| Jumlah bid di bawah estimasi | Sistem mewajibkan bid minimal sesuai harga estimasi Generator |
| Koneksi terputus | Coba kirim ulang saat koneksi stabil |
| Status limbah berubah | Mungkin limbah sudah dibooking Aggregator lain, cari limbah lain |

---

## 9.4 Pickup Tidak Bisa Dikonfirmasi

| Masalah | Solusi |
|---------|--------|
| GPS tidak terdeteksi | Pastikan GPS perangkat aktif, coba di luar ruangan |
| Foto gagal diupload | Periksa ukuran file, gunakan format JPG/PNG |
| Berat tidak terisi | Field berat aktual wajib diisi sebelum konfirmasi |
| Tombol konfirmasi tidak aktif | Pastikan semua field wajib (foto, GPS, berat) sudah diisi |

---

## 9.5 Kontak Bantuan

Jika masalah tidak terselesaikan, hubungi tim WoodLoop melalui:

| Saluran | Detail |
|---------|--------|
| **Email** | woodloop.app@gmail.com |
| **Website** | woodloop.pasarjepara.com |

Sertakan informasi berikut saat melapor:
1. **Nama akun**
2. **Deskripsi masalah** (jelaskan langkah yang sudah dilakukan)
3. **Screenshot** jika ada pesan error
4. **Waktu kejadian**
