# Bab 9: Panduan Buyer (Konsumen Akhir)

---

**Buyer** adalah konsumen akhir yang membeli produk upcycled dari Converter.

**Contoh pengguna Buyer:** Pembeli perorangan, pemilik toko souvenir, desainer interior, kolektor.

---

## 9.1 Marketplace Produk

**Marketplace** adalah halaman utama Buyer — menampilkan semua produk upcycled dari para Converter.

![Marketplace](screenshots/22-buyer-marketplace.png)
*Gambar 9.1 — Marketplace produk upcycled*

| Fitur | Fungsi |
|-------|--------|
| **Pencarian** | Cari produk berdasarkan nama atau kata kunci |
| **Kategori** | Filter: Furniture, Dekorasi, Aksesoris, Mainan |
| **Filter Harga** | Range harga minimal - maksimal |
| **Filter Bahan** | Filter berdasarkan jenis kayu |

Setiap produk ditampilkan dalam kartu: foto, nama, nama Converter, harga, dan tombol detail.

| Kategori | Contoh Produk |
|----------|---------------|
| **Furniture** | Meja, kursi, rak, lemari |
| **Dekorasi** | Vas, patung, hiasan dinding |
| **Aksesoris** | Gelang, kalung, gantungan kunci |
| **Mainan** | Puzzle kayu, mainan edukasi |
| **Peralatan** | Talenan, kotak, tempat pensil |

### Detail Produk & Traceability

Klik kartu produk untuk melihat detail lengkap termasuk **Cerita Traceability** — perjalanan produk dari Supplier hingga Converter. Setiap tahap menampilkan nama pihak, tanggal, lokasi, dan dampak lingkungan.

## 9.2 Keranjang & Checkout

### Keranjang Belanja

| Fitur | Fungsi |
|-------|--------|
| **Tambah Qty** | Menambah jumlah produk |
| **Kurang Qty** | Mengurangi jumlah produk |
| **Hapus** | Menghapus item dari keranjang |
| **Checkout** | Lanjut ke pembayaran |

### Checkout

1. Buka **Keranjang** → klik **"Checkout"**
2. Isi **Alamat Pengiriman**: nama penerima, nomor telepon, alamat lengkap, kota, kode pos
3. Pilih **Metode Pembayaran**:

| Metode | Biaya | Proses |
|--------|:-----:|--------|
| **Midtrans** | Flat per transaksi | Otomatis, realtime |
| **Dompet WoodLoop** | Gratis | Instan (jika saldo cukup) |
| **Transfer Bank** | Gratis | Manual (1×24 jam) |

4. Klik **"Bayar Sekarang"**

---

## 9.3 Tracking Pesanan

### Timeline Pesanan

```
Menunggu Bayar → Dibayar → Diproses → Dikirim → Diterima → Selesai
```

| Status | Aksi Buyer |
|--------|-----------|
| **Menunggu Bayar** | Bayar sekarang / Batalkan pesanan |
| **Dibayar** | Tunggu Converter memproses |
| **Dikirim** | Lacak pengiriman |
| **Diterima** | Klik **"Konfirmasi Terima"** |
| **Selesai** | Beri rating & ulasan |

---

## 9.4 Scan QR Code

Setiap produk upcycled memiliki **QR Code unik** yang bisa di-scan.

| Metode | Cara |
|--------|------|
| **Kamera HP** | Arahkan kamera ke QR Code → tap link yang muncul |
| **Aplikasi Android** | Buka WoodLoop → tap ikon QR Scanner → arahkan kamera |
| **Upload Foto (Web)** | Klik QR Scanner → **"Upload Foto QR"** → pilih foto |

> QR Code bisa di-scan dengan kamera HP bawaan, tidak perlu aplikasi khusus.
