# Bab 1: Pendahuluan

---

## 1.1 Apa Itu WoodLoop?

**WoodLoop** adalah platform digital ekonomi sirkular untuk industri kayu dan furnitur di Jepara, Jawa Tengah. Platform ini menghubungkan seluruh aktor dalam rantai nilai kayu — dari pemasok kayu gelondongan, pengrajin yang menghasilkan limbah, pengepul, pengrajin upcycle, pembeli, hingga pemerintah — dalam satu ekosistem terpadu.

Tujuan utama WoodLoop adalah **mengubah limbah kayu menjadi sumber daya bernilai ekonomi** sekaligus melacak dampak lingkungannya.

### Masalah yang Dipecahkan

| Masalah | Solusi WoodLoop |
|---------|----------------|
| Limbah kayu dibakar/dibuang | Platform menjembatani penjualan limbah ke pihak yang membutuhkan |
| Rantai pasok terfragmentasi | Satu platform untuk 6 peran dengan alur terintegrasi |
| Harga tidak transparan | Marketplace dengan harga jelas, sistem bidding untuk limbah |
| Asal-usul produk tidak jelas | QR traceability menampilkan seluruh riwayat produk |
| Pengrajin kesulitan bahan baku | Akses ke kayu mentah dari Supplier dan limbah dari Aggregator |

## 1.2 Siapa Saja Penggunanya?

WoodLoop memiliki **7 peran pengguna** yang merepresentasikan setiap mata rantai dalam ekosistem industri kayu Jepara:

| Peran | Deskripsi | Contoh |
|-------|-----------|--------|
| **Supplier** | Pemasok kayu gelondongan | Pedagang kayu, pemilik sawmill |
| **Generator** | Penghasil limbah kayu | Pengrajin mebel, workshop |
| **Aggregator** | Pengepul & logistik | Pengumpul limbah, gudang sortir |
| **Converter** | Pengolah limbah jadi produk | Pengrajin kreatif, startup daur ulang |
| **Desainer** | Konsultan desain sirkular | Desainer produk, konsultan kreatif |
| **Buyer** | Konsumen akhir | Pembeli perorangan, toko retail |
| **Enabler** | Pemantau ekosistem | Dinas LH, Asosiasi mebel |

![Halaman Pemilihan Peran](screenshots/04-role-selection.png)
*Gambar 1.1 — Halaman pemilihan peran saat registrasi*

**Panduan memilih peran:**

| Jika Anda... | Pilih peran... |
|-------------|---------------|
| Memiliki stok kayu gelondongan dan ingin menjualnya | **Supplier** |
| Memiliki usaha mebel dan menghasilkan potongan kayu | **Generator** |
| Memiliki armada untuk menjemput dan menyortir limbah | **Aggregator** |
| Kreatif mengolah limbah menjadi produk unik | **Converter** |
| Ingin membeli produk ramah lingkungan | **Buyer** |
| Bekerja di instansi terkait pengelolaan lingkungan | **Enabler** |

> **Catatan:** Setiap pengguna hanya bisa memilih **satu peran** saat registrasi. Peran tidak bisa diubah setelah akun dibuat. Namun, satu orang bisa memiliki beberapa akun dengan peran berbeda menggunakan email yang berbeda.

## 1.3 Platform yang Didukung

### Web (Browser Desktop & Mobile)

Akses WoodLoop melalui browser di `https://woodloop.app`. Didukung di Chrome, Firefox, Safari, Edge, dan Samsung Internet.

**Keunggulan:**
- Tidak perlu install aplikasi
- Produk muncul di hasil pencarian Google (SEO)
- PWA — bisa diinstall sebagai aplikasi dari browser

### Android (Capacitor Hybrid)

Aplikasi Android untuk pengalaman paling optimal — terutama untuk role yang bekerja di lapangan.

**Cara install APK:**
1. Download file APK dari website WoodLoop
2. Buka file APK di perangkat Android
3. Izinkan "Install dari sumber tidak dikenal" jika diminta
4. Ikuti petunjuk instalasi

> **Catatan:** Fitur yang membutuhkan kamera dan GPS (seperti setor limbah, treasure map, konfirmasi pickup) akan bekerja lebih optimal di aplikasi Android. Di web browser, fitur-fitur tersebut menggunakan fallback berbasis HTML5.

## 1.4 Istilah Penting (Glossary)

| Istilah | Arti |
|---------|------|
| **Raw Timber** | Kayu gelondongan mentah yang belum diolah, dijual oleh Supplier |
| **Offcut** | Potongan kayu sisa produksi mebel |
| **Shaving** | Serutan kayu tipis hasil proses penghalusan |
| **Sawdust** | Serbuk gergaji — limbah paling halus dari pemotongan |
| **Logs End** | Ujung-ujung kayu gelondongan yang tidak terpakai |
| **Bidding** | Sistem lelang dimana Aggregator mengajukan harga untuk limbah |
| **Pickup** | Proses penjemputan limbah dari Generator oleh Aggregator |
| **Traceability** | Ketertelusuran — kemampuan melacak asal-usul produk |
| **QR Code** | Kode batang 2 dimensi untuk mengakses halaman traceability |
| **Treasure Map** | Peta interaktif lokasi limbah yang tersedia |
| **Design Clinic** | Galeri inspirasi dan resep desain untuk mengolah limbah |
| **Wallet** | Dompet digital untuk transaksi antar pengguna |
| **Midtrans** | Payment gateway untuk pembayaran Buyer ke Converter |
| **Impact Metrics** | Metrik dampak lingkungan — CO₂ tersimpan, limbah terpakai |
