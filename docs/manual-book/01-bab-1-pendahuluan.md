# Bab 1: Pendahuluan

---

## 1.1 Apa Itu WoodLoop?

**WoodLoop** adalah platform **ekonomi sirkular** (circular economy) berbasis web dan mobile yang menghubungkan seluruh pemangku kepentingan dalam industri kayu di Jepara. Tujuan utamanya adalah **mengubah limbah kayu menjadi produk bernilai ekonomi**, sekaligus mengurangi dampak lingkungan dari industri mebel yang telah menjadi ikon Jepara selama berabad-abad.

### Visi

> *"Menjadikan Jepara sebagai pusat ekonomi sirkular kayu dunia yang berkelanjutan, transparan, dan menguntungkan semua pihak."*

### Misi

1. **Mengurangi limbah kayu** yang dibakar atau dibuang ke lingkungan
2. **Menciptakan nilai ekonomi baru** dari limbah kayu melalui daur ulang dan upcycling
3. **Meningkatkan transparansi rantai pasok** melalui teknologi QR traceability
4. **Memberdayakan pengrajin lokal** dengan akses ke bahan baku terjangkau dan pasar yang lebih luas
5. **Mendukung program pemerintah** dalam pengelolaan limbah dan keberlanjutan lingkungan

### Masalah yang Dipecahkan

| Masalah | Solusi WoodLoop |
|---------|----------------|
| Limbah kayu dibakar/dibuang | Platform menjembatani penjualan limbah ke pihak yang membutuhkan |
| Rantai pasok terfragmentasi | Satu platform untuk 6 peran dengan alur yang terintegrasi |
| Harga tidak transparan | Marketplace dengan harga jelas, sistem bidding untuk limbah |
| Asal-usul produk tidak jelas | QR traceability menampilkan seluruh riwayat produk |
| Pengrajin kesulitan bahan baku | Akses ke kayu mentah dari Supplier dan limbah dari Aggregator |

## 1.2 Siapa Saja Penggunanya?

WoodLoop memiliki **7 peran pengguna** yang merepresentasikan setiap mata rantai dalam ekosistem industri kayu Jepara:

| Peran | Deskripsi | Contoh |
|-------|-----------|--------|
| 🌲 **Supplier** | Pemasok kayu gelondongan | Pedagang kayu, pemilik sawmill |
| 🏭 **Generator** | Penghasil limbah kayu | Pengrajin mebel, workshop |
| 🚛 **Aggregator** | Pengepul & logistik | Pengumpul limbah, gudang sortir |
| ♻️ **Converter** | Pengolah limbah jadi produk | Pengrajin kreatif, startup daur ulang |
| ✏️ **Desainer** | Konsultan desain sirkular | Desainer produk, konsultan kreatif |
| 🛒 **Buyer** | Konsumen akhir | Pembeli perorangan, toko retail |
| 📊 **Enabler** | Pemantau ekosistem | Dinas LH, Asosiasi mebel |

![Halaman Pemilihan Peran](screenshots/04-role-selection.png)
*Gambar 1.1 — Halaman pemilihan peran saat registrasi*

### Siapa yang Cocok Menggunakan WoodLoop?

| Jika Anda... | Maka peran Anda adalah... |
|-------------|--------------------------|
| Memiliki stok kayu gelondongan dan ingin menjualnya | **Supplier** |
| Memiliki usaha mebel dan menghasilkan potongan kayu | **Generator** |
| Memiliki armada untuk menjemput dan menyortir limbah | **Aggregator** |
| Kreatif mengolah limbah menjadi produk unik | **Converter** |
| Ingin membeli produk ramah lingkungan | **Buyer** |
| Bekerja di instansi terkait pengelolaan lingkungan | **Enabler** |

> **Catatan:** Setiap pengguna hanya bisa memilih **satu peran** saat registrasi. Peran tidak bisa diubah setelah akun dibuat. Namun, satu orang bisa memiliki beberapa akun dengan peran berbeda menggunakan email yang berbeda.

## 1.3 Platform yang Didukung

WoodLoop dapat diakses melalui dua platform:

### 🌐 Web (Browser Desktop & Mobile)

| Browser | Dukungan |
|---------|----------|
| Google Chrome | ✅ Optimal |
| Mozilla Firefox | ✅ Optimal |
| Safari (macOS/iOS) | ✅ Optimal |
| Microsoft Edge | ✅ Optimal |
| Samsung Internet | ✅ Optimal |

**Cara akses:** Buka alamat `https://woodloop.app` di browser Anda.

**Keunggulan:**
- ✅ Tidak perlu install aplikasi
- ✅ SEO — produk muncul di hasil pencarian Google
- ✅ QR Traceability — landing page publik tanpa login
- ✅ PWA — bisa diinstall sebagai aplikasi dari browser

### 📱 Android (Capacitor Hybrid)

Aplikasi Android dapat diinstall melalui:
- **APK** — download dari website (untuk sideload)
- **Google Play Store** — *(coming soon)*

**Cara install APK:**
1. Download file APK dari website WoodLoop
2. Buka file APK di perangkat Android
3. Izinkan "Install dari sumber tidak dikenal" jika diminta
4. Ikuti petunjuk instalasi

**Keunggulan versi Android:**
- ✅ Akses kamera native untuk foto limbah & produk
- ✅ GPS native untuk Treasure Map & pickup
- ✅ Push notification realtime
- ✅ QR Scanner native

> **Catatan:** Fitur yang membutuhkan kamera dan GPS (seperti setor limbah, treasure map, konfirmasi pickup) akan bekerja lebih optimal di aplikasi Android. Di web browser, fitur-fitur tersebut menggunakan fallback berbasis HTML5.

## 1.4 Istilah Penting (Glossary)

| Istilah | Arti |
|---------|------|
| **Circular Economy** | Sistem ekonomi yang meminimalkan limbah dengan memaksimalkan penggunaan kembali sumber daya (reduce, reuse, recycle) |
| **Upcycling** | Mengolah limbah menjadi produk yang memiliki nilai lebih tinggi dari bahan aslinya |
| **Raw Timber** | Kayu gelondongan mentah yang belum diolah, dijual oleh Supplier |
| **Offcut** | Potongan kayu sisa produksi mebel — bentuk paling umum dari limbah kayu |
| **Shaving** | Serutan kayu tipis hasil proses penghalusan |
| **Sawdust** | Serbuk gergaji — limbah paling halus dari proses pemotongan |
| **Logs End** | Ujung-ujung kayu gelondongan yang tidak terpakai |
| **Bidding** | Sistem lelang dimana Aggregator mengajukan harga untuk limbah yang tersedia |
| **Pickup** | Proses penjemputan limbah dari Generator oleh Aggregator |
| **Traceability** | Ketertelusuran — kemampuan melacak asal-usul produk dari bahan baku hingga jadi |
| **QR Code** | Kode batang 2 dimensi yang bisa dipindai untuk mengakses halaman traceability produk |
| **PocketBase** | Backend database dan autentikasi yang digunakan WoodLoop |
| **PWA** | Progressive Web App — website yang bisa diinstall seperti aplikasi native |
| **Treasure Map** | Peta interaktif yang menampilkan lokasi limbah yang tersedia untuk dijemput |
| **Design Clinic** | Galeri inspirasi dan resep desain untuk mengolah limbah menjadi produk |
| **Wallet** | Dompet digital untuk transaksi antar pengguna WoodLoop |
| **Midtrans** | Payment gateway untuk pembayaran Buyer ke Converter |
| **Impact Metrics** | Metrik dampak lingkungan — CO₂ tersimpan, limbah terpakai, dll |
