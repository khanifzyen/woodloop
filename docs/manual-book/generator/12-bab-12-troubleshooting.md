# Bab 12: Troubleshooting

---

## 12.1 Tidak Bisa Login

| Masalah | Solusi |
|---------|--------|
| Lupa password | Klik **"Lupa Kata Sandi?"** di halaman login, ikuti instruksi reset |
| Email tidak terdaftar | Pastikan mendaftar dengan peran Generator terlebih dahulu |
| Salah peran | Pastikan memilih **Generator** saat login, bukan peran lain |
| Browser error | Coba gunakan browser berbeda atau mode incognito |

> **🔑 Lupa Kata Sandi?** Jika Anda lupa kata sandi, klik tautan "Lupa Kata Sandi?" pada halaman login. Masukkan email Anda dan ikuti petunjuk yang dikirim ke email tersebut.

---

## 12.2 Foto Gagal Upload

| Masalah | Solusi |
|---------|--------|
| File terlalu besar | Maksimal 5 MB per file |
| Format tidak didukung | Gunakan JPG, PNG, atau WebP |
| Koneksi terputus | Pastikan koneksi internet stabil |
| File rusak | Coba buka file di komputer, jika tidak bisa berarti file rusak |
| Terlalu banyak foto | Maksimal 5 foto per limbah atau produk |

---

## 12.3 Pembayaran Gagal

| Masalah | Solusi |
|---------|--------|
| Saldo tidak mencukupi | Pilih metode pembayaran lain atau isi ulang saldo |
| Koneksi terputus saat bayar | Coba lagi, cek status pesanan di halaman Pesanan Kayu |
| Snap Midtrans tidak muncul | Aktifkan pop-up di browser, refresh halaman |
| Waktu habis | Midtrans Snap memiliki batas waktu, ulangi dari awal |
| Status tidak berubah | Refresh halaman, jika masih sama hubungi support |

> **⚠️ Perhatian:** Jika pembayaran sudah berhasil tapi status masih "Menunggu Pembayaran", tunggu beberapa saat dan refresh halaman. Jika tidak berubah dalam 30 menit, hubungi tim WoodLoop.

---

## 12.4 Tidak Ada Penawaran Masuk

| Kemungkinan | Saran |
|-------------|-------|
| Belum ada Aggregator yang tertarik | Pastikan foto dan deskripsi limbah jelas |
| Harga terlalu tinggi | Coba turunkan estimasi harga |
| Status masih "Draft" | Pastikan limbah sudah disetor dengan benar |
| Baru sebentar | Tunggu beberapa saat, Aggregator perlu waktu melihat |

> **💡 Tips:** Untuk meningkatkan peluang mendapatkan penawaran, pastikan:
> - Foto limbah jelas dan dari beberapa sudut
> - Jenis kayu dan bentuk dipilih dengan tepat
> - Estimasi harga wajar sesuai pasar
> - Deskripsi ditambahkan untuk informasi lebih detail
