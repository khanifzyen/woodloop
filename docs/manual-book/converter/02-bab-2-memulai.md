# Bab 2: Memulai

---

## 2.1 Akses ke Aplikasi

Akses WoodLoop melalui browser web di alamat:

```
https://woodloop.pasarjepara.com
```

**Kebutuhan Sistem:**
- Browser: Chrome, Firefox, Edge, atau Safari versi terbaru
- Koneksi internet stabil
- Akun Converter yang sudah terdaftar

---

## 2.2 Login

1. Buka halaman login di `https://woodloop.pasarjepara.com/login`

   ![Halaman Login](../screenshots/02-login.png)
   *Gambar 2.1 — Halaman login WoodLoop*

2. Masukkan **email** dan **kata sandi** yang sudah didaftarkan
3. Klik tombol **"Masuk"**
4. Setelah berhasil, Anda akan diarahkan ke **Dashboard Converter**

> **🔑 Lupa Kata Sandi?** Klik link "Lupa Kata Sandi?" di halaman login, masukkan email Anda, dan ikuti instruksi yang dikirim ke email.

> **⚠️ Perhatian:** Pastikan email dan password benar. Jika gagal login, periksa kembali input Anda. Browser tidak menampilkan pesan error detail untuk keamanan akun.

---

## 2.3 Navigasi Antarmuka

Setelah login, Anda akan melihat antarmuka utama dengan beberapa elemen navigasi:

![Dashboard Converter](../screenshots/18-converter-dashboard.png)
*Gambar 2.2 — Dashboard Converter*

### 1. Sidebar Kiri

Sidebar menampilkan menu navigasi khusus Converter:

| Menu | Ikon | Halaman | Fungsi |
|------|------|---------|--------|
| **Dashboard** | 📊 | `/converter/dashboard` | Ringkasan bisnis kreatif |
| **Pasar Bahan** | 🏪 | `/converter/marketplace/materials` | Marketplace bahan limbah |
| **Katalog Produk** | 📦 | `/converter/catalog` | Kelola produk upcycled & QR |
| **Riwayat Transaksi** | 🕐 | `/converter/marketplace/history` | Riwayat pembelian bahan |
| **Klinik Desain** | 📖 | `/design-clinic` | Konsultasi & resep desain |

### 2. Navigasi Atas (Navbar)

| Elemen | Fungsi |
|--------|--------|
| 🌓 **Mode Gelap** | Tombol toggle gelap/terang |
| 🌐 **Ganti Bahasa** | Beralih EN/ID |
| 🔔 **Notifikasi** | Notifikasi masuk |
| 👤 **Avatar** | Dropdown: Profil | Dompet | Keluar |

### 3. Breadcrumb

Di bawah navbar, terdapat *breadcrumb* yang menunjukkan posisi halaman saat ini. Contoh:
```
Converter > Dashboard
```

---

## 2.4 Mode Gelap & Ganti Bahasa

### Mode Gelap / Terang

Klik tombol 🌓 di pojok kanan atas navbar untuk mengganti antara:
- **Mode Terang** (default) — latar putih
- **Mode Gelap** — latar gelap, nyaman di malam hari

### Ganti Bahasa

Klik tombol 🌐 di navbar untuk mengganti bahasa antarmuka:
- **Bahasa Indonesia** (default)
- **English**
