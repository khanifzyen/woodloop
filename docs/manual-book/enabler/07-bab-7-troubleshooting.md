# Bab 7: Troubleshooting

---

## 7.1 Tidak Bisa Login

**Masalah:** Gagal login meskipun email dan password sudah dimasukkan.

**Solusi:**
1. Pastikan email yang dimasukkan sudah benar (tidak ada spasi di depan/belakang)
2. Pastikan password benar — password bersifat **case-sensitive**
3. Periksa koneksi internet
4. Jika lupa password, klik **"Lupa Kata Sandi?"** di halaman login
5. Masukkan email terdaftar, ikuti instruksi reset yang dikirim ke email

> **⚠️ Perhatian:** Akun Enabler hanya dibuat oleh administrator. Jika Anda belum memiliki akun Enabler, hubungi tim WoodLoop — tidak bisa registrasi mandiri.

---

## 7.2 Data Tidak Muncul

**Masalah:** Dashboard menampilkan "Belum ada data" atau grafik kosong.

**Solusi:**
1. **Cek filter periode** — Pastikan dropdown periode tidak membatasi terlalu sempit. Coba pilih "Semua Waktu"
2. **Refresh halaman** — Tekan F5 atau klik tombol refresh browser
3. **Tunggu beberapa saat** — Data dampak diperbarui secara berkala. Jika platform baru digunakan, data mungkin belum tersedia
4. Jika masalah berlanjut, hubungi tim WoodLoop

---

## 7.3 Verifikasi Gagal

**Masalah:** Tombol verifikasi tidak berfungsi atau perubahan status tidak tersimpan.

**Solusi:**
1. **Refresh halaman** — Tekan F5, lalu coba verifikasi ulang
2. **Periksa koneksi** — Pastikan koneksi internet stabil
3. **Cek hak akses** — Hanya Enabler yang bisa memverifikasi pengguna. Pastikan Anda login sebagai Enabler
4. Jika verifikasi tetap gagal, coba melalui halaman **Detail User** (klik baris pengguna) untuk verifikasi yang lebih lengkap

---

## 7.4 Ekspor Data Tidak Terdownload

**Masalah:** Setelah klik "Export CSV", file tidak terdownload.

**Solusi:**
1. **Cek pop-up blocker** — Beberapa browser memblokir download otomatis. Izinkan download dari WoodLoop
2. **Cek folder download** — File mungkin sudah terdownload tanpa notifikasi. Cek folder Downloads
3. **Coba browser lain** — Chrome atau Firefox biasanya paling kompatibel
4. **Pastikan ada data** — Jika dashboard kosong, file CSV juga akan kosong. Pilih "Semua Waktu" di filter periode
