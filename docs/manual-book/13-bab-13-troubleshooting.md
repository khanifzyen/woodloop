# Bab 13: Troubleshooting & FAQ

---

## 13.1 Masalah Login

| Masalah | Solusi |
|---------|--------|
| **"Email tidak terdaftar"** | Periksa kembali email, atau daftar akun baru |
| **"Kata sandi salah"** | Klik **"Lupa Kata Sandi"** untuk reset (tautan berlaku 1 jam) |
| **Tetap di halaman login** | Hapus cache & cookies browser, atau buka mode incognito |
| **"Akun diblokir"** | Hubungi support (email/WhatsApp) |
| **Redirect ke halaman tertentu** | Pastikan login dengan peran yang benar |

> **Lupa email terdaftar?** Hubungi support dengan nama lengkap, nomor telepon, dan perkiraan tanggal registrasi.

---

## 13.2 Masalah Upload Foto

| Masalah | Penyebab | Solusi |
|---------|----------|--------|
| **Foto gagal upload** | Ukuran > 2 MB | Kompres foto terlebih dahulu |
| **Format tidak didukung** | Bukan JPG/PNG/WebP | Konversi ke format yang didukung |
| **Kamera tidak terbuka** | Izin kamera belum diberikan | Izinkan akses kamera di browser/pengaturan HP |
| **Upload lambat** | Koneksi internet lemot | Coba gunakan WiFi, atau kompres foto |

### Tips Foto yang Baik

| Kriteria | Saran |
|----------|-------|
| **Pencahayaan** | Ambil foto di tempat terang, hindari bayangan |
| **Sudut** | Ambil dari beberapa sudut (depan, samping, atas) |
| **Latar belakang** | Bersih, tidak berantakan |
| **Resolusi** | Minimal 800×600 piksel |

## 13.3 Masalah Pembayaran

| Masalah | Solusi |
|---------|--------|
| **Pembayaran gagal** | Cek saldo atau gunakan metode lain |
| **Status "pending" terlalu lama** | Tunggu 5 menit, refresh halaman |
| **Midtrans error** | Coba lagi 10 menit kemudian |
| **Salah transfer jumlah** | Hubungi penerima via Chat untuk refund |

### Setelah Transfer Manual

1. Simpan bukti transfer (screenshot)
2. Buka **Pesanan** → **"Konfirmasi Pembayaran"**
3. Upload bukti transfer
4. Tunggu penjual mengkonfirmasi (maks 1×24 jam)

### Refund & Pembatalan

| Skenario | Kebijakan |
|----------|-----------|
| **Pesanan dibatalkan sebelum bayar** | Tidak ada biaya |
| **Pesanan dibatalkan setelah bayar** | Refund 100% ke dompet WoodLoop (1×24 jam) |
| **Produk rusak saat pengiriman** | Dokumentasi foto, hubungi Converter |

## 13.4 Masalah GPS & Lokasi

| Masalah | Solusi |
|---------|--------|
| **Lokasi tidak akurat** | Aktifkan GPS, ke tempat terbuka |
| **"Izin lokasi ditolak"** | Izinkan di pengaturan browser/HP |
| **Treasure Map kosong** | Perluas radius pencarian |
| **Koordinat tidak tersimpan** | Coba lagi di tempat dengan sinyal lebih baik |

### Cara Mengaktifkan GPS

**Android:** Pengaturan → Lokasi → Aktifkan → pilih mode **"Akurasi Tinggi"**

**Browser:** Klik ikon 🔒 di address bar → Lokasi → Izinkan → Refresh halaman

---

## 13.5 Masalah Notifikasi

| Masalah | Solusi |
|---------|--------|
| **Tidak mendapat notifikasi** | Izinkan di pengaturan browser/HP |
| **Notifikasi hanya di dalam app** | Install APK Android untuk push native |
| **Terlalu banyak notifikasi** | Sesuaikan preferensi notifikasi di Pengaturan |

### Cara Mengaktifkan Notifikasi

**Browser:** Klik ikon 🔒 di address bar → Notifikasi → Izinkan

**Aplikasi Android:** Pengaturan HP → Aplikasi → WoodLoop → Notifikasi → Aktifkan
