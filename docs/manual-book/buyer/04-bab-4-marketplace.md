# Bab 4: Marketplace

---

Halaman **Marketplace** adalah toko utama tempat Anda dapat menjelajahi semua produk upcycled yang tersedia dari para Converter (pengrajin kreatif) di ekosistem WoodLoop.

![\1](../screenshots/\2)
*Gambar 4.1 — Halaman Marketplace Buyer*

---

## 4.1 Menjelajahi Produk

Produk ditampilkan dalam bentuk **grid kartu** yang responsif — 2 kolom di layar ponsel, 4 kolom di layar desktop.

Setiap kartu produk menampilkan:

| Elemen | Keterangan |
|--------|------------|
| **Foto** | Gambar utama produk (aspect ratio 4:3) |
| **Nama Produk** | Nama produk upcycled |
| **Badge Kategori** | Label kategori (Furniture, Decor, dll) |
| **Harga** | Harga jual dalam Rupiah |
| **Nama Converter** | Nama pengrajin pembuat produk |
| **Tombol + Keranjang** | Tambah ke keranjang belanja |

### Interaksi dengan Kartu Produk

- **Klik pada foto/nama** — membuka halaman detail produk
- **Klik tombol +** — menambahkan produk ke keranjang (dengan notifikasi sukses)
- **Hover** — efek zoom dan bayangan pada kartu

---

## 4.2 Kategori Produk

Di bawah bilah pencarian, terdapat **tab kategori** untuk menyaring produk berdasarkan jenis:

| Kategori | Contoh Produk |
|----------|---------------|
| **Semua** | Menampilkan seluruh produk |
| **Furniture** | Meja, kursi, lemari, rak dari kayu daur ulang |
| **Decor** | Vas, hiasan dinding, lampu, jam dinding |
| **Accessories** | Jam tangan, gelang, tas, dompet |
| **Art** | Patung, lukisan kayu, instalasi seni |
| **Lainnya** | Produk yang tidak masuk kategori di atas |

**Cara menggunakan:**
1. Klik tab kategori yang diinginkan
2. Grid akan langsung menyaring produk sesuai kategori
3. Klik tab yang sama lagi untuk menghapus filter

---

## 4.3 Pencarian & Filter Harga

### Pencarian Teks

Ketik kata kunci di kolom pencarian untuk mencari produk berdasarkan:
- Nama produk
- Deskripsi produk

Pencarian akan bekerja secara real-time saat Anda mengetik.

### Filter Rentang Harga

Untuk menyaring produk berdasarkan harga:

1. Klik tombol **ikon Sliders (🔀)** di samping kolom pencarian
2. Panel filter harga akan terbuka:

   ```
   ┌──────────────────────────────────────┐
   │ Rentang Harga                         │
   │                                       │
   │  [ Harga Min ] — [ Harga Max ]        │
   │                                       │
   │           [ Reset ]                   │
   └──────────────────────────────────────┘
   ```

3. Masukkan harga minimum dan/atau maksimum
4. Klik **"Reset"** untuk menghapus filter harga

---

## 4.4 Urutkan Produk

Dropdown **urutkan** memungkinkan Anda mengatur tampilan produk:

| Opsi | Urutan |
|------|--------|
| **Terbaru** | Produk paling baru di atas (default) |
| **Terlaris** | Produk dengan penjualan terbanyak |
| **Termurah** | Harga terendah ke tertinggi |
| **Termahal** | Harga tertinggi ke terendah |

---

## 4.5 Tambah ke Keranjang

Dari kartu produk, Anda dapat langsung menambahkan produk ke keranjang:

1. Klik tombol **ikon Keranjang (+)** pada kartu produk
2. Notifikasi akan muncul: **"[Nama Produk] ditambahkan ke keranjang"**
3. Untuk melihat isi keranjang, klik tombol **ikon Keranjang** di sebelah dropdown urutkan

### Tombol Cepat Lainnya

- **🛒 Ikon Keranjang** — langsung ke halaman keranjang
- **❤️ Ikon Heart** — langsung ke halaman wishlist (hanya untuk Buyer yang sudah login)
