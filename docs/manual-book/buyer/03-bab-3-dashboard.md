# Bab 3: Dashboard Buyer

---

Halaman Dashboard Buyer adalah halaman utama yang muncul setelah login. Dashboard menampilkan sambutan dan kartu fitur utama yang tersedia untuk Buyer.

![\1](../screenshots/\2)
*Gambar 3.1 — Dashboard Buyer*

---

## 3.1 Halaman Dashboard

Dashboard menampilkan:

### Selamat Datang

Bagian atas halaman menampilkan pesan selamat datang khusus Buyer:

```
Selamat datang di WoodLoop, [Nama Anda]!
Jelajahi produk daur ulang, lacak pesanan, dan lihat dampak lingkungan.
```

### Kartu Fitur

Dua kartu fitur utama yang langsung bisa diakses:

| Kartu | Ikon | Deskripsi |
|-------|------|-----------|
| **Marketplace** | 🏪 | Produk upcycled berkualitas dari pengrajin Jepara |
| **Pesanan Saya** | 📋 | Lacak status pesanan Anda |

Setiap kartu dapat diklik untuk langsung menuju ke halaman terkait.

---

## 3.2 Menu Cepat

Dari Dashboard, Anda dapat mengakses halaman utama melalui sidebar kiri atau dengan mengklik kartu fitur yang tersedia.

**Akses ke Marketplace:**
- Klik kartu **Marketplace** di Dashboard
- Atau klik **Marketplace** di sidebar kiri
- Atau buka langsung: `/buyer/marketplace`

**Akses ke Pesanan:**
- Klik kartu **Pesanan Saya** di Dashboard
- Atau klik **Pesanan Saya** di sidebar kiri
- Atau buka langsung: `/buyer/orders`
