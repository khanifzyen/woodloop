# Bab 11: Toko Penjual

---

Halaman **Toko Penjual** menampilkan profil lengkap dari Converter (pengrajin) dan semua produk yang mereka jual.

![\1](../screenshots/\2)
*Gambar 11.1 — Halaman toko penjual*

---

## 11.1 Profil Penjual

Bagian atas halaman menampilkan profil Converter:

```
┌──────────────────────────────────────────────┐
│                                              │
│  [A] Nama Converter        ✓ Terverifikasi    │
│      Converter                                │
│      Nama Workshop               [Hubungi]    │
│                                              │
│  📍 Alamat workshop                           │
│  📞 08123456789                               │
│                                              │
│  Bio: Pengrajin kayu jati sejak 2010...       │
│                                              │
└──────────────────────────────────────────────┘
```

| Elemen | Keterangan |
|--------|------------|
| **Avatar** | Lingkaran dengan inisial nama |
| **Nama** | Nama lengkap Converter |
| **Badge Terverifikasi** | ✓ Biru — menandakan akun sudah diverifikasi |
| **Role** | Label peran (Converter) |
| **Nama Workshop** | Nama workshop/toko |
| **Alamat** | Alamat workshop |
| **Telepon** | Nomor kontak |
| **Bio** | Deskripsi profil |
| **Tombol Hubungi** | Buka chat dengan penjual |

---

## 11.2 Produk Penjual

Di bawah profil, terdapat grid produk milik penjual tersebut:

```
Produk (5)
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│ Foto │ │ Foto │ │ Foto │ │ Foto │
│ Nama │ │ Nama │ │ Nama │ │ Nama │
│ Harga│ │ Harga│ │ Harga│ │ Harga│
└──────┘ └──────┘ └──────┘ └──────┘
```

Setiap kartu produk menampilkan:
- **Foto** — Gambar utama produk
- **Nama** — Nama produk (link ke detail)
- **Harga** — Harga jual
- **Badge Kategori** — Label kategori

> Klik produk untuk membuka halaman detail. Jika penjual belum memiliki produk, akan tampil **"Belum ada produk tersedia"**.
