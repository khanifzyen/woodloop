# Bab 7: Troubleshooting

---

## 7.1 Tidak Bisa Login

**Masalah:** Gagal login meskipun email dan password sudah dimasukkan.

**Solusi:**
1. Pastikan email yang dimasukkan sudah benar (tidak ada spasi di depan/belakang)
2. Pastikan password benar — password bersifat **case-sensitive**
3. Periksa koneksi internet
4. Jika lupa password, klik **"Lupa Kata Sandi?"** di halaman login
5. Masukkan email terdaftar, ikuti instruksi reset yang dikirim ke email

> **Catatan:** Untuk keamanan, sistem tidak menampilkan detail error login secara spesifik. Jika gagal, periksa kembali email dan password Anda.

---

## 7.2 Artikel Gagal Publikasi

**Masalah:** Tombol publikasi tidak merespon atau artikel tetap berstatus draf.

**Solusi:**
1. Refresh halaman dan coba klik tombol 👁️ (publikasikan) sekali lagi
2. Pastikan koneksi internet stabil
3. Jika masih gagal, coba buka detail artikel dan klik **"Simpan sebagai Draf"** lalu coba publikasikan lagi

---

## 7.3 Data Tidak Muncul

**Masalah:** Artikel atau catatan desain yang baru dibuat tidak muncul di daftar.

**Solusi:**
1. **Tunggu beberapa detik** — sistem akan memperbarui tampilan secara otomatis
2. **Refresh halaman** — tekan F5 atau klik tombol refresh browser
3. Jika masih muncul setelah refresh, coba **clear cache browser** atau buka di tab baru

> **Catatan:** Data akan langsung tersimpan di database. Tampilan akan terupdate dalam hitungan detik.

---

## 7.4 Gambar Tidak Bisa Upload

**Masalah:** Gambar sampul artikel atau sketsa catatan desain gagal diupload.

**Solusi:**
1. Periksa format gambar — gunakan JPG, PNG, atau WebP
2. Pastikan ukuran gambar tidak terlalu besar (maks 5 MB per file)
3. Periksa jumlah file — maksimal 3 file sketsa per catatan desain
4. Coba gunakan browser lain (Chrome atau Firefox)
5. Refresh halaman dan coba upload ulang
