# Bab 12: Troubleshooting & FAQ

---

## 12.1 Masalah Login

| Masalah | Penyebab | Solusi |
|---------|----------|--------|
| **"Email tidak terdaftar"** | Email salah / belum registrasi | Periksa kembali email, atau daftar akun baru |
| **"Kata sandi salah"** | Lupa kata sandi / typo | Klik "Lupa Kata Sandi" untuk reset |
| **Halaman tetap di login** | Cache browser menyimpan sesi lama | Hapus cache & cookies browser, atau buka mode incognito |
| **Tidak bisa login setelah reset password** | Tautan reset kedaluwarsa | Ulangi proses reset (tautan berlaku 1 jam) |
| **"Akun diblokir"** | Melanggar aturan / dicurigai spam | Hubungi support (email/WhatsApp) |
| **Redirect terus ke halaman tertentu** | Role tidak sesuai dengan halaman | Pastikan login dengan peran yang benar |

### Saya lupa password. Bagaimana?

1. Buka halaman login
2. Klik **"Lupa Kata Sandi?"**
3. Masukkan email terdaftar
4. Buka email → klik tautan reset
5. Buat password baru (min. 8 karakter)
6. Login dengan password baru

### Saya lupa email terdaftar. Bagaimana?

Hubungi support WoodLoop dengan menyertakan:
- Nama lengkap
- Nomor telepon terdaftar
- Perkiraan tanggal registrasi

## 12.2 Masalah Upload Foto

| Masalah | Penyebab | Solusi |
|---------|----------|--------|
| **Foto gagal upload** | Ukuran > 2 MB | Kompres foto terlebih dahulu |
| **Format tidak didukung** | Bukan JPG/PNG/WebP | Konversi ke format yang didukung |
| **Foto terlalu gelap** | Pencahayaan kurang | Ambil ulang dengan pencahayaan cukup |
| **Kamera tidak terbuka** | Izin kamera belum diberikan | Izinkan akses kamera di browser/pengaturan HP |
| **Upload lambat** | Koneksi internet lemot | Coba gunakan WiFi, atau kompres foto |

### Tips Foto yang Baik

| Kriteria | Saran |
|----------|-------|
| ☀️ **Pencahayaan** | Ambil foto di tempat terang, hindari bayangan |
| 📐 **Sudut** | Ambil dari beberapa sudut (depan, samping, atas) |
| 🧹 **Latar belakang** | Bersih, tidak berantakan |
| 📏 **Skala** | Sertakan objek pembanding (penggaris, botol) |
| 🖼️ **Resolusi** | Minimal 800×600 piksel |

### Cara Kompres Foto (Android)

1. Buka **Google Photos** atau **Gallery**
2. Pilih foto → **Share** → **Save as compressed**
3. Atau gunakan aplikasi **Photo Compress** dari Play Store

## 12.3 Masalah Pembayaran

| Masalah | Penyebab | Solusi |
|---------|----------|--------|
| **Pembayaran gagal** | Saldo tidak cukup / kartu ditolak | Cek saldo atau gunakan metode lain |
| **Status "pending" terlalu lama** | Pembayaran belum dikonfirmasi sistem | Tunggu 5 menit, refresh halaman |
| **Sudah bayar tapi status belum berubah** | Keterlambatan notifikasi | Hubungi support dengan bukti transfer |
| **Midtrans error** | Gangguan server pembayaran | Coba lagi 10 menit kemudian |
| **Salah transfer jumlah** | Input nominal salah | Hubungi penerima via Chat untuk refund |

### Yang Harus Dilakukan Setelah Transfer Manual

1. Simpan **bukti transfer** (screenshot)
2. Buka halaman **Pesanan**
3. Klik **"Konfirmasi Pembayaran"**
4. Upload bukti transfer
5. Tunggu penjual mengkonfirmasi (maks 1×24 jam)

### Refund & Pembatalan

| Skenario | Kebijakan |
|----------|-----------|
| **Pesanan dibatalkan sebelum bayar** | Tidak ada biaya |
| **Pesanan dibatalkan setelah bayar** | Refund 100% ke dompet WoodLoop (1×24 jam) |
| **Produk tidak sesuai** | Hubungi Converter via Chat untuk kesepakatan |
| **Produk rusak saat pengiriman** | Dokumentasi foto, hubungi Converter |

## 12.4 Masalah GPS & Lokasi

| Masalah | Penyebab | Solusi |
|---------|----------|--------|
| **Lokasi tidak akurat** | GPS mati / sinyal lemah | Aktifkan GPS, ke tempat terbuka |
| **"Izin lokasi ditolak"** | Izin belum diberikan | Izinkan di pengaturan browser/HP |
| **Treasure Map kosong** | Tidak ada limbah di sekitar | Perluas radius pencarian |
| **Koordinat tidak tersimpan** | GPS timeout | Coba lagi di tempat dengan sinyal lebih baik |

### Cara Mengaktifkan GPS

**Android:**
1. Buka **Pengaturan** → **Lokasi**
2. Aktifkan **"Gunakan Lokasi"**
3. Pilih mode **"Akurasi Tinggi"** (GPS + WiFi + Mobile)

**Browser (Chrome):**
1. Klik ikon **🔒** di address bar
2. Pilih **"Lokasi"** → **"Izinkan"**
3. Refresh halaman

## 12.5 Masalah Notifikasi

| Masalah | Penyebab | Solusi |
|---------|----------|--------|
| **Tidak mendapat notifikasi** | Izin notifikasi belum diberikan | Izinkan di pengaturan browser/HP |
| **Notifikasi hanya di dalam app** | Push notification belum aktif | Install APK Android untuk push native |
| **Notifikasi muncul tapi tidak bersuara** | Volume notifikasi mati | Cek pengaturan suara HP |
| **Terlalu banyak notifikasi** | Semua notifikasi aktif | Sesuaikan preferensi notifikasi di Pengaturan |

### Cara Mengaktifkan Notifikasi

**Di Browser:**
1. Klik ikon **🔒** di address bar
2. Cari **"Notifikasi"** → pilih **"Izinkan"**
3. Refresh halaman

**Di Aplikasi Android:**
1. Buka **Pengaturan HP** → **Aplikasi** → **WoodLoop**
2. **Notifikasi** → Aktifkan semua izin
