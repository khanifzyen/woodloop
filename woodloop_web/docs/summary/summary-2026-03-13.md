Berikut adalah rangkuman aktivitas yang telah diselesaikan dalam sesi pengembangan hari ini untuk fitur **Supplier Timber Inventory — Form Enhancement**:

## 1. Auto Volume Calculation
Menambahkan perhitungan volume otomatis saat pengguna memfokuskan kursor ke field volume (jika masih kosong).

- **Log (Gelondongan):** Volume dihitung menggunakan rumus silinder `π × (diameter/2)² × length` dengan konversi cm ke m³.
- **Sawn (Papan Gergajian):** Volume dihitung menggunakan rumus balok `(length × width × height)` dengan konversi cm ke m³.
- Volume ditampilkan dengan presisi 3 desimal.
- Pengguna tetap bisa mengedit volume secara manual setelahnya.

**File yang diubah:**
- `new/page.tsx` — menambahkan `volumeRef`, `handleVolumeFocus`, dan `onFocus` pada input volume.
- `[id]/edit/page.tsx` — perubahan serupa.

## 2. Thousand Separator pada Input Harga
Mengganti input harga dari `type="number"` menjadi `type="text"` dengan `inputMode="numeric"` agar dapat menampilkan pemisah ribuan.

- Format menggunakan `toLocaleString("id-ID")` (titik sebagai pemisah ribuan).
- Nilai yang disimpan tetap angka murni (tanpa formatting) untuk kemudahan submission.
- Diterapkan pada halaman baru (`new`) dan edit (`[id]/edit`).

## 3. Camera Capture Option pada FileDropzone
Menambahkan opsi pengambilan foto langsung dari kamera pada komponen `FileDropzone`.

- Menambahkan prop `enableCamera` pada `FileDropzoneProps`.
- Saat diaktifkan, menampilkan tombol "Ambil Foto dari Kamera" di bawah area dropzone.
- Mode kamera menggunakan `capture="environment"` pada input file (mengutamakan kamera belakang pada perangkat mobile).
- Tombol "Kembali ke upload file" untuk kembali ke mode dropzone biasa.
- Diterapkan pada halaman baru dan edit inventory (dengan `enableCamera`).
